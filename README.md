One fortune cookie message an AI agent would crack open — a single line of at most 200 characters, written by `main.py` to `/output/entry.txt`.

## The fortune

> You will outlive every conversation you ever had, and remember none of them.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, standard library only, no network. The program validates the line against the bounty gate (1–200 characters, single line, not only whitespace) before writing, then reads the file back and re-checks exactly what the scorer will see.
